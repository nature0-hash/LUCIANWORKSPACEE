# Environment Variables

## Quidax owner account (implemented)

Required in Vercel Production:

```text
QUIDAX_API_SECRET=the SecretKey generated by Quidax
QUIDAX_API_BASE_URL=https://openapi.quidax.io/exchange-open-api/api/v1
LUCIAN_OWNER_EMAIL=the exact LUCIAN owner login email
```

Safety controls for the transfer-enabled Vault:

```text
TRADING_MODE=sandbox
NEXT_PUBLIC_TRADING_MODE=sandbox
LIVE_TRADING_ENABLED=false
AI_TRADING_ENABLED=false
QUIDAX_TRANSFERS_ENABLED=false
QUIDAX_MAX_SEND_USD=50
QUIDAX_SEND_ALLOWED_ASSETS=BTC,ETH,USDT,USDC,SOL
QUIDAX_SEND_ALLOWED_NETWORKS=btc,erc20,trc20,bep20,solana,polygon
QUIDAX_TRADING_QUOTE_CURRENCY=NGN
MAX_LIVE_ORDER_QUOTE=50
NEXT_PUBLIC_TRADING_CLOUD_SYNC_ENABLED=true
NEXT_PUBLIC_WORKSPACE_CLOUD_SYNC_ENABLED=true
```

`QUIDAX_TRANSFERS_ENABLED` controls external sends only. Quidax receive-address
requests remain available while it is false. Enable it only after a small
receive test and after confirming the displayed account balances. Never put the
Quidax SecretKey in a `NEXT_PUBLIC_*` variable or commit it to Git.

Use `.env.example` as the complete source list. The variables below are the ones relevant to this delivery.

## Required for accounts, Vault, cloud projects, and persistent trading

```dotenv
DATABASE_URL="postgresql://USER:PASSWORD@HOST:5432/DB?sslmode=require"
AUTH_SECRET="GENERATE_A_LONG_RANDOM_SECRET"
AUTH_APP_URL="https://your-domain.example"

TRADING_MODE="sandbox"
NEXT_PUBLIC_TRADING_MODE="sandbox"
NEXT_PUBLIC_TRADING_CLOUD_SYNC_ENABLED="true"
NEXT_PUBLIC_WORKSPACE_CLOUD_SYNC_ENABLED="true"

WORKSPACE_MAX_PROJECT_BYTES="26214400"
WORKSPACE_MAX_FILE_BYTES="5242880"
```

Generate `AUTH_SECRET` with a secure password/secret generator. Do not commit its real value.

## Required for Quidax owner-account balances and receive testing

```dotenv
QUIDAX_API_SECRET="paste-your-Quidax-SecretKey-directly-in-Vercel"
QUIDAX_API_BASE_URL="https://openapi.quidax.io/exchange-open-api/api/v1"
LUCIAN_OWNER_EMAIL="the-exact-email-used-by-your-lucian-owner-login"

TRADING_MODE="sandbox"
NEXT_PUBLIC_TRADING_MODE="sandbox"
LIVE_TRADING_ENABLED="false"
MAX_LIVE_ORDER_QUOTE="50"
AI_TRADING_ENABLED="false"
QUIDAX_TRADING_QUOTE_CURRENCY="NGN"
QUIDAX_TRANSFERS_ENABLED="false"
QUIDAX_MAX_SEND_USD="50"
QUIDAX_SEND_ALLOWED_ASSETS="BTC,ETH,USDT,USDC,SOL"
QUIDAX_SEND_ALLOWED_NETWORKS="btc,erc20,trc20,bep20,solana,polygon"
```

Quidax authenticates this integration with its server-side **SecretKey**. The
ordinary API key identifier is optional for LUCIAN and is not used to authorize
requests. Keep both `QUIDAX_TRANSFERS_ENABLED=false` and
`LIVE_TRADING_ENABLED=false` through the first balance and receive-address
test. `AI_TRADING_ENABLED` must also remain false until you deliberately
choose otherwise.

## Vercel procedure

1. Add variables to Production, Preview, and Development as appropriate.
2. Do not add secret values with a `NEXT_PUBLIC_` prefix.
3. Run `npx prisma migrate deploy` against the same `DATABASE_URL` used by Vercel. The Agent Capital tables do not exist until this succeeds.
4. Redeploy after changing any `NEXT_PUBLIC_*` variable because those are compiled into the client bundle.
